كيفية إصلاح خطأ Rules

لو شفت خطأ permission-denied أو client is offline:
1. افتح Firebase Console
2. اختار مشروعك > Firestore Database > Rules
3. الصق هذا واحفظ Publish:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

هذا للتجربة فقط، بعد ما تتأكد شغال ممكن نضيق الصلاحيات
